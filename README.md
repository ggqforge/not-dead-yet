# Not Dead Yet（不死图腾名称动画）

**简称：NDY**（取自 Not Dead Yet 的首字母）

给不死图腾用铁砧改个名字，触发保命动画时，名字就会显示在动画图腾的正中央。

**Minecraft 1.21.1 · Fabric · 纯客户端**（服务器不用装，也不需要 Fabric API）

---

## 一、效果

1. 用铁砧把不死图腾改名，例如 `第二条命`、`应急[尺寸:2]`、`应急[颜色:红色;尺寸:2]`
2. 带着它被致命伤害打死，图腾触发保命动画
3. 动画播放期间，名字画在**图腾正中央、而且在图腾前面**，字号**全程跟着图腾缩放走**

没改过名的普通图腾**不显示任何文字**，不会每次保命都冒出「不死图腾」四个字。

| 名字 | 显示效果 |
| --- | --- |
| `第二条命` | 图腾金 `#EADB84`，带阴影 |
| `应急[尺寸:2]` | 图腾金，字号 2 倍 |
| `应急[颜色:红色;尺寸:2]` | 红色，字号 2 倍 |
| `凤凰[color:red;size:2]` | 同上，键值写英文也行 |
| `神像[c:#FF8800]` | 十六进制颜色 |
| `朝霞[c:红,橙,黄]` | 平滑渐变 |
| `垂帘[c:y红,蓝]` | 纵向渐变 |
| `斜辉[c:t红,黄,绿]` | 斜向渐变 |

**其它显示名字的地方也会同步**：物品栏里鼠标悬停时的说明（tooltip）、快捷栏上方切换物品时弹出的名称。
这两处都会**隐藏末尾的方括号设置**，并用和动画一样的颜色显示 ——
也就是 `应急[颜色:红色;尺寸:2]` 在它们那里都是红色的「应急」两个字。

---

## 二、安装

需要 **Minecraft 1.21.1** 和 **Fabric Loader**。

1. 装好 Fabric Loader 1.21.1
   （[官方安装器](https://fabricmc.net/use/installer/) 选 1.21.1 后 Install；国内用 PCL2 等启动器更省事）
2. 启动一次游戏，让它生成 `.minecraft` 目录
3. 把 `not-dead-yet-x.y.z+mc1.21.1.jar` 放进 `.minecraft/mods/`
   （没有 `mods` 文件夹就自己新建一个，注意名字是全小写）
4. 启动时选 **Fabric 1.21.1** 那个版本

**不需要 Fabric API，服务器也不用装。** 这是纯客户端模组，装在服务器上没有任何作用。

## 三、改颜色和字号

在名字的**末尾**加一个方括号写设置：

```
应急[颜色:红色;尺寸:2]
```

冒号、分号、逗号**中英文都认**，键名**不分大小写**（`[S:2]` 和 `[s:2]` 一样）。

### 3.1 键名

| 键 | 用途 |
| --- | --- |
| `c` `颜色` `色` `color` `colour` `渐变` `gradient` | 颜色 |
| `s` `尺寸` `大小` `size` | 字号 |

**键名也可以省略** —— 能当数字读的算字号，其余算颜色：

```
应急[yred,blue;2]     等于 [c:yred,blue;s:2]
应急[red,blue]        等于 [c:red,blue]
应急[2]               等于 [s:2]
应急[红色]             等于 [c:红色]
```

> ⚠️ 省略键名有两点要注意：
>
> 1. **数字优先当字号**：所以 `[2]` 是「字号 2」，不是颜色代码 `§2`。
>    想用数字颜色代码请显式写键，例如 `[c:2]`。
> 2. **名字以 `[颜色]` 结尾会被当成设置吃掉**：比如图腾叫 `药水[红]`，
>    显示出来只剩 `药水` 而且颜色变红。要保留这种结尾，写成带键但**键不认识**的形式
>    即可，例如 `[备注:红]`（不认识的键不会被吞）。

### 3.2 颜色可以怎么写

| 形态 | 例子 |
| --- | --- |
| **纯色** | `[c:红色]`、`[c:c]`、`[c:#FF8800]` |
| **渐变** | `[c:红,蓝]`、`[c:红,黄,绿,蓝]` |

颜色值有四种写法：

| 写法 | 例子 |
| --- | --- |
| **中文名** | `红` `金色` `淡紫` `深蓝` …… |
| **英文名** | `red` `gold` `light_purple` …… |
| **代码字符** | `c` `f` `9` ……（就是原版 `§c` 里的那个字母，**只写字母**） |
| **十六进制** | `#FF8800`，也可以简写 `#F80` |

多个颜色用**逗号**隔开就是**平滑渐变**（`[c:#FF0000,#0000FF]` 这样混着写也行）。

| --- | --- | --- |

| 深蓝 暗蓝 | `dark_blue` `navy` | 深蓝 |
| 深绿 暗绿 | `dark_green` | 深绿 |
| 深青 暗青 | `dark_aqua` `teal` | 深青 |

| 金 金色 橙 橙色 | `gold` `orange` | 金 |
| 灰 灰色 | `gray` `grey` `silver` | 灰 |
| 深灰 暗灰 | `dark_gray` `dark_grey` | 深灰 |
| 蓝 蓝色 | `blue` | 蓝 |
| 绿 绿色 | `green` `lime` | 绿 |
| 青 青色 天蓝 浅蓝 | `aqua` `cyan` | 青 |

原版只有 16 种颜色。想要更精准的颜色请用十六进制，例如 `[c:#FF8800]`。

### 3.3 渐变方向

在颜色**前面**加一个字母：

| 字母 | 方向 |
| --- | --- |
| 不写，或 `x` | 横向，左 → 右（默认） |
| `y` | 纵向，上 → 下 |
| `t` | 斜向，左上 → 右下 |

```
[c:红,蓝]          横向
[c:y红,蓝]         纵向
[c:t红,黄,绿]      斜向
[yred,blue;2]     简写：纵向，字号 2 倍
```

> `y` 既是方向字母，也是颜色 `yellow` 的首字母（`t` 与 `teal` 同理）。
> 模组会**先试「方向字母 + 颜色」，失败再退回把整串当颜色**，
> 所以 `[c:yellow]` 得到的是黄色，而不是「纵向的 ellow」。

### 3.4 字号

```
[s:2]      2 倍
[s:1.5]    1.5 倍
[s:0.5]    0.5 倍
[2]        简写，等于 [s:2]
```

不写就是 **1 倍**。允许范围 **0.25 ~ 6**，超出会自动夹到边界。

> 名字**不换行**，也不做宽度限制。字号是跟着图腾缩放的（图腾在动画中会从 50 放大到 225 像素），
> 所以名字太长时动画中段可能横向超出屏幕。建议把名字控制在 **20 个字符以内**，
> 或者用 `[s:0.5]` 压小一点。

### 3.5 写错了会怎样

解析失败时，**方括号会原样显示在名字里**，不会被悄悄吞掉 —— 写错了你一眼就能看见。

| 写法 | 原因 |
| --- | --- |
| `[备用]` | 既不是字号也不是颜色 |
| `[备注:无]` | 认不出这个键 |
| `[尺寸:大]` | 字号必须是数字 |
| `[颜色:大红]` | 没有叫「大红」的颜色 |
| `[颜色:红,大蓝]` | 渐变里有一个颜色不认识 |

想查具体原因，打开 `.minecraft/logs/latest.log` 搜索 `[命名]`，
模组会把解析结果和失败原因都打印在里面。

### 3.6 常见问题

**名字最长能写多少？**
原版铁砧限制 **50 个字符**，方括号里的设置也算在内。

**能不能用 `§` 写颜色？**
不行。原版铁砧会把 `§` 这个字符直接过滤掉，根本存不进名字里 ——
本模组正是为此改用方括号的。方括号、冒号、分号、逗号、中文在铁砧里都是合法字符。

**为什么铁砧里能看到方括号，鼠标放到图腾上却看不到？**
这是故意的。方括号里是给模组读的设置，不算名字的一部分，所以显示名字的地方
（物品栏说明、快捷栏上方的名称）都会把它隐藏掉，颜色和动画一致。
铁砧里保留原文是为了让你能接着改颜色和字号，不会因为重新命名一次就把设置弄丢。

**改过名了，为什么保命时不出字？**
依次检查三点：

1. 名字确实改成功了（铁砧结果栏里显示的是你填的内容）
2. 是**你自己**的图腾触发的保命 —— 别人的保命动画不在你屏幕上播
3. 名字末尾那个方括号是不是写错了。写错的话它会原样显示在名字里，你一眼就能看见

**按 F1 隐藏 HUD 时还会显示吗？**
不会，它会和动画中的图腾一起隐藏，和原版行为一致。
